# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Crypto operators who want persistent named agents (scouts / bots) that work toward goals on-chain without babysitting every step.

## Product Purpose

Squadrons lets a user create named crypto agents (name, avatar, description, chain), give them goals, and watch them work. Observe-by-default; spend is enabled per agent within tight caps.

## Positioning

Not a chat with tools — a roster of characterful crypto agents with goals, memory, and an activity trail. Closest UI reference for the desk shell: Grok Bot (three-column agent list / chat / context).

## Key Capabilities

- My Agents roster; create with fixed orb avatars
- Goal intake → working → agent-declared complete → idle
- Observe-mode tools (balances, web, etc.); spend later
- In-app chat / activity (no Discord in v1)

## Constraints

- First chain: Base (8453)
- Default auto-trade cap: $10 (when spend exists)
- No user-facing skill/playbook manager in v1
- No cron / routines UI in v1
- Auth: local-dev stub now; Privy later

## Brand Commitments

- Product name: Squadrons
- Avatars: fixed 8 orb faces
- Desk layout preference (user-pinned): Grok Bot–like three columns

## Accessibility

Keyboard-reachable navigation and controls; contrast suitable for dark desk UI.
