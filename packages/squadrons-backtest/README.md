# squadrons-backtest

First-party Backtest plugin for simulated equity curves (chart card in chat).

- Desk: **Plugins → Backtest → Enable** (no API key)
- Tool: `run_backtest` (Cordis — not remote MCP)
- Engine: deterministic simulation today; Tenderly later

The catalog entry still lives under Plugins; the host loads this package as a Cordis overlay when enabled.
